# Psy Goa Trance Music Project

A collection of psychedelic goa trance tracks composed using Strudel REPL with original samples from renowned psy trance artists.

## Project Structure

- `tracks/` - Main composition files
- `samples/` - Audio samples organized by type
- `patterns/` - Reusable pattern libraries
- `docs/` - Documentation and references

## Getting Started

1. Open Strudel REPL in your browser: https://strudel.cc/
2. Load the composition files from the `tracks/` directory
3. Experiment with different patterns and samples
